# Task: Explicit Cancellation Rollback Override with Durable Walk Undo Journal

## Problem Statement
Plan R established the global single-active-walk gate, cancellation checkpoints, adapter-owned savepoints, and run-owned cleanup, but its cancellation cleanup only deletes three provenance-keyed tables. The explicit override now requires that cancelled or process-interrupted walk progress from every writer in walks 2a–2i not survive, while preserving audit/history and never overwriting human edits or later-run changes. Implement a durable writer-side `walk_undo_entry` journal: each mutation records a per-row before/after image in the same savepoint as the data write; rollback replays entries in reverse sequence with after-image/CAS and key-free/FK conflict guards; startup replay occurs before any new admission. Plan R remains intact as predecessor/context and is not overwritten; this plan replaces its delete-based cleanup for cancelled/interrupted runs.
